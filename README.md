# ⛩️ 聖地巡礼動画スタジオ (Seichi Studio)

神社・聖地を案内する YouTube 動画（横 16:9 / 縦 9:16 ショート）を、ブラウザだけで作れる動画編集ツールです。
写真・動画・ナレーション・BGM を並べ、神社紹介に特化したテロップやアクセス案内を重ねて、MP4 で書き出せます。

## 主な機能

| 分類 | 内容 |
|---|---|
| おまかせ編集 | 撮影した動画をまとめて入れると、撮影順に並べ、話している部分は残し、景色はブレの少ない見どころだけを切り出して指定の長さに編集。Claude がテロップ・チャプター・案内を下書き |
| テロップ | 聖地名カード（名称・所在地・御祭神・ご利益）、解説テロップ、参拝作法カード。長い文は自動で折り返し・縮小 |
| 字幕 | 日本語・英語の2言語。Claude による英訳（用語集で固有名詞の表記を統一）、SRT 字幕ファイルの書き出し |
| 映像 | 写真のケン・バーンズ効果（ズーム・パン・注視点指定）、動画クリップ（元音声の音量調整つき）、分割・トリミング・スナップ |
| 音声 | ブラウザでのナレーション録音、BGM・自然音、ナレーション中の BGM 自動ダッキング、フェード、ラウドネス測定（ITU-R BS.1770 / LUFS）と自動調整、出力レベルメーター |
| 案内 | アクセス案内カード（所在地・最寄り駅・駐車場・参拝時間＋地図画像または簡易地図）、YouTube 概要欄用チャプターの生成 |
| 書き出し | MP4（H.264 / AAC・1080p・30fps）。非対応環境では WebM。サムネイル画像（PNG）の作成 |
| その他 | 元に戻す／やり直し、キーボードショートカット、神社プリセット（戸隠神社・出雲大社・伊勢神宮） |

## 動作環境

- **ブラウザ**: 最新版の Google Chrome または Microsoft Edge を推奨（動画書き出しに WebCodecs を使用）。
  その他のブラウザでは、書き出しが WebM 形式になる、または利用できない場合があります。
- **Node.js**: 20.19 以上（22 LTS 推奨）※ 開発サーバーの起動・ビルドに必要

### ブラウザテスト（npm run test:e2e）

アプリを本番用にビルドし、Chromium を自動で操作して、人が使うのと同じ流れを確かめます。
写真・音声・動画などのテスト素材はその場で作るので、リポジトリに素材ファイルはありません。
Claude API は呼ばず、テストが応答を返すので、API キーも料金も不要です。

| 分類 | 確かめていること |
|---|---|
| 編集 | 分割（S）・削除（Delete）・元に戻す／やり直す、選ぶだけでは履歴に残らない、入力欄でショートカットが誤作動しない、再生、テロップの追加と編集、録音（R）、縦横の切り替え |
| 保存 | 再読み込みで編集と写真が残る、プロジェクトファイルの保存と読込（API キーが含まれない）、壊れたファイルの読込、プリセットの確認 |
| 翻訳 | 翻訳結果が英語欄に入る、送る内容（キー・モデル・用語集）、キーが拒否されたときのエラー表示 |
| 書き出し | 写真の順番と時刻・テロップの焼き込み（MP4）、BGM が話している間だけ下がる・ナレーションが入る（WebM）、中止 |
| おまかせ編集 | 撮影時刻の順に並ぶ、話している部分を残す、撮影場所から案内カード、Claude の下書きの配置、元に戻す |

初回だけ、テスト用のブラウザを入れます。

```bash
npx playwright install chromium
# Linux / WSL では、ブラウザが使うライブラリも必要です（管理者パスワードを聞かれます）
sudo npx playwright install-deps chromium
```

失敗したときは `npx playwright show-report` で、どの操作で止まったかを画面つきで確認できます。

テスト用の Chromium（Linux）は AAC（MP4 の音声）を書き出せないため、音声つきの書き出しは WebM で確かめています。
Windows / Mac の Chrome で使われる「音声つき MP4」の組み合わせは、自動テストでは確かめていません。

## 英訳（Claude API）の設定

1. [Claude Console](https://platform.claude.com/) で API キーを作成します（従量課金）。
2. アプリの「翻訳」タブで API キーを入力して保存し、翻訳モデルを選びます。
   - Claude Opus 5.5（高品質・標準） / Sonnet 5.5（バランス） / Haiku 4.5（低コスト）
3. 各行の「この行だけ再翻訳」または「全テロップを一括翻訳」を押します。

API キーはこのブラウザ内にのみ保存され、翻訳時に Anthropic の API へ直接送信されます。
プロジェクトの保存ファイル（JSON）には含まれません。

## おまかせ編集（動画から自動で下書き）

ヘッダーの「おまかせ編集」から、撮影した動画をまとめて入れるだけで編集の下書きを作れます。解析はブラウザの中で行い、動画そのものはどこにも送信されません（Claude を使う場合のみ、各場面の静止画を1枚ずつ Anthropic の API に送ります）。

1. 動画ファイルをまとめてドロップし、神社の名前と仕上がりの長さ（横 1〜10分 / 縦 30〜60秒）を選びます。
2. 「おまかせ編集を開始」を押すと、次の処理を自動で行います。
   - **並べ替え**: 動画に記録された撮影日時の順（記録がない動画があるときはファイル名の順）
   - **話し声**: 撮影者が話している部分を検出し、切らずに残します。BGM を追加すると、話している間は自動で音量が下がります
   - **見どころ**: 話していない場面は、手ぶれ・ピンぼけ・暗さを判定し、安定した場面だけを切り出して指定の長さに収めます。撮り始めと撮り終わりのブレも除きます
   - **アクセス案内**: 動画に撮影場所（GPS）が記録されていれば、その座標でアクセス案内カードを作ります
3. Claude API キーを設定していれば、各場面の静止画を Claude に見せて、聖地名カード・解説テロップ・参拝作法・チャプター・動画タイトルを日本語と英語で作らせることもできます（API の利用料金がかかります）。

結果は今のタイムラインに置き換わります（Ctrl+Z で元に戻せます）。御祭神・ご利益・アクセス情報は、メモ欄に書いた情報が優先され、それ以外は Claude の知識による下書きです。公開前に必ず確認してください。
話し声の検出は音の大きさと声の高さによる簡易判定のため、風や鈴の音などを声と判定したり、小さな声を見落としたりすることがあります。

## データの保存について

- プロジェクトと素材（写真・動画・音声・録音）は、**このブラウザの中**（IndexedDB）に自動保存されます。
  同じファイルを何度追加しても（おまかせ編集のやり直しを含む）、保存されるのは1つだけです。
- 今のプロジェクトで使わなくなった素材は、**使われなくなってから14日後**に、アプリを開いたときに自動で削除されます。
- ヘッダーの「保存」で書き出す JSON には、**素材ファイル自体は含まれません**。
  同じブラウザでは「読込」で素材も復元されますが、別の PC・ブラウザや、素材が削除された後（上記の14日後）は、素材を追加し直す必要があります。
- ブラウザの「サイトデータの削除」を行うと素材も消えます。元の写真・動画・音声は手元に残しておいてください。

## 地図について

アクセス案内カードの地図は2種類から選べます。

- **地図画像（推奨）**: 正確な地図をアップロードして表示します。
  アプリ内の「OpenStreetMapでこの座標を開く」から地図を開き、「共有」→「画像」でダウンロードした画像を使えます。
  その場合は出典表記「© OpenStreetMap contributors」を残してください。
- **簡易地図**: 緯度・経度のピンと座標を表示する装飾的な図です（実際の道路などは表示されません）。

## 既知の制限

- 書き出しはブラウザのメモリ上で行います。長尺（数十分以上）の動画ではメモリ不足になる可能性があります。
- 動画素材の形式（コーデック）によっては、ブラウザが読み込めず書き出しに反映されない場合があります（書き出し完了時に警告を表示します）。
- PC での利用を想定しています（スマートフォンの画面には対応していません）。
