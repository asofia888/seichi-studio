# ⛩️ 聖地巡礼動画スタジオ (Seichi Studio)

神社・聖地を案内する YouTube 動画（横 16:9 / 縦 9:16 ショート）を、ブラウザだけで作れる動画編集ツールです。
写真・動画・ナレーション・BGM を並べ、神社紹介に特化したテロップやアクセス案内を重ねて、MP4 で書き出せます。

## 主な機能

| 分類 | 内容 |
|---|---|
| おまかせ編集 | 撮影した動画をまとめて入れると、撮影順に並べ、話している部分は残し、景色はブレの少ない見どころだけを切り出して指定の長さに編集。Claude がテロップ・チャプター・案内を下書き |
| テロップ | 聖地名カード（名称・所在地・御祭神・ご利益）、解説テロップ、参拝作法カード。長い文は自動で折り返し・縮小 |
| 字幕 | 日本語・英語の2言語。Claude による英訳（用語集で固有名詞の表記を統一。一括翻訳は全行を1回で送り、訳語をそろえる）、SRT 字幕ファイルの書き出し |
| 映像 | 写真のケン・バーンズ効果（ズーム・パン・注視点指定）、動画クリップ（元音声の音量調整つき）、分割・トリミング・スナップ、つなぎ（ディゾルブ・黒/白フェード）、Bロール（本編の上に重ねる映像）、色補正（明るさ・コントラスト・彩度・色温度）、再生速度（0.25〜4倍）、周辺減光（強さ調整・オフ） |
| 編集 | 削除すると後ろのクリップが詰まる（リップル削除）、クリップは重ならず元の素材の長さを超えてトリムされない、並べ替え、動画の長さは最後の映像＋エンディングに自動で合わせる |
| 音声 | ブラウザでのナレーション録音、BGM・自然音、ナレーション中の BGM 自動ダッキング、フェード、ラウドネス測定（ITU-R BS.1770 / LUFS）と自動調整、出力レベルメーター |
| 案内 | アクセス案内カード（所在地・最寄り駅・駐車場・参拝時間＋地図画像または簡易地図）、YouTube 概要欄用チャプターの生成 |
| 書き出し | MP4（H.264 / AAC）。1080p / 4K、24 / 30 / 60fps。非対応環境では WebM。音量を -14 LUFS（YouTube 標準）などにそろえ、リミッターで音割れを防止。長い動画は保存先のファイルへ直接書き込み、音声も10秒ずつ作るので、長さに比例してメモリを使わない。サムネイル画像（PNG）の作成 |
| プロジェクト | 複数のプロジェクトをブラウザ内に保存して切り替え（新規作成・複製・削除）。素材ごと1つのファイルに保存するバックアップ（.sacred.zip）と、別のパソコン・ブラウザでの読み込み |
| その他 | 元に戻す／やり直し、キーボードショートカット、キーボードだけでの操作と読み上げソフトへの対応、神社プリセット（戸隠神社・出雲大社・伊勢神宮） |

## 動作環境

- **ブラウザ**: 最新版の Google Chrome または Microsoft Edge を推奨（動画書き出しに WebCodecs を使用）。
  その他のブラウザでは、書き出しが WebM 形式になる、または利用できない場合があります。
- **Node.js**: 20.19 以上（22 LTS 推奨）※ 開発サーバーの起動・ビルドに必要

### ブラウザテスト（npm run test:e2e）

アプリを本番用にビルドし、Chromium を自動で操作して、人が使うのと同じ流れを確かめます。
写真・音声・動画などのテスト素材はその場で作るので、リポジトリに素材ファイルはありません。
Claude API は呼ばず、テストが応答を返すので、API キーも料金も不要です。

| 分類 | 確かめていること |
|---|---|
| 編集 | 分割（S）・削除（Delete）で後ろが詰まる・元に戻す／やり直す、選ぶだけでは履歴に残らない、クリップがドラッグで重ならない、最後の写真を消すと動画と BGM が短くなる、写真のない部分の表示、周辺減光、入力欄やダイアログ表示中にショートカットが誤作動しない、どのダイアログも Esc で閉じる、再生、テロップの追加と編集、録音（R）、縦横の切り替え |
| 保存 | 再読み込みで編集と写真が残る、プロジェクトファイルの保存と読込（API キーが含まれない）、壊れたファイル・項目の欠けたファイルの読込、画面の表示に失敗したときの案内と復旧、プリセットの確認 |
| プロジェクト | 新規作成と切り替え（それぞれの内容が残る）、複製と削除、バックアップを別のブラウザで読み込むと写真ごと戻る、バックアップでないファイルの読込 |
| 翻訳 | 翻訳結果が英語欄に入る、一括翻訳が1回の依頼にまとまる、送る内容（キー・モデル・用語集）、キーが拒否されたときのエラー表示 |
| 書き出し | 写真の順番と時刻・テロップの焼き込み・写真のない部分は黒（MP4）、ディゾルブ・色補正・Bロール、BGM が話している間だけ下がる・ナレーションが入る・音量が -14 LUFS にそろう（WebM）、音が重なっても割れない、動画の音が使う部分だけ正しい時刻に入る・60fps、10秒ごとの音声の継ぎ目や繰り返しの頭で音が途切れない（動画の音・5分を超える音源・繰り返す自然音）、4K、中止 |
| おまかせ編集 | 撮影時刻の順に並ぶ、話している部分を残す、撮影場所から案内カード、Claude の下書きの配置、元に戻す |
| アクセシビリティ | 全タブ・全ダイアログの自動検査（axe、WCAG 2.1 A / AA：名前・役割・コントラスト）、ダイアログ内でのフォーカスの移動と復帰、タブの矢印キー操作、タイムラインのアイテムをキーボードで選ぶ・動かす・長さを変える、動きを減らす設定 |

初回だけ、テスト用のブラウザを入れます。

```bash
npx playwright install chromium
# Linux / WSL では、ブラウザが使うライブラリも必要です（管理者パスワードを聞かれます）
sudo npx playwright install-deps chromium
```

失敗したときは `npx playwright show-report` で、どの操作で止まったかを画面つきで確認できます。

テスト用の Chromium（Linux）は AAC（MP4 の音声）を書き出せないため、音声つきの書き出しは WebM で確かめています。
Windows / Mac の Chrome で使われる「音声つき MP4」の組み合わせは、自動テストでは確かめていません。

## 英訳（Claude API）の設定

1. [Claude Console](https://platform.claude.com/) で API キーを作成します（従量課金）。
2. アプリの「翻訳」タブで API キーを入力して保存し、翻訳モデルを選びます。
   - Claude Opus 5.5（高品質・標準） / Sonnet 5.5（バランス） / Haiku 4.5（低コスト）
3. 各行の「この行だけ再翻訳」または「全テロップを一括翻訳」を押します。

API キーはこのブラウザ内にのみ保存され、翻訳時に Anthropic の API へ直接送信されます。
プロジェクトの保存ファイル（JSON）には含まれません。

## おまかせ編集（動画から自動で下書き）

ヘッダーの「おまかせ編集」から、撮影した動画をまとめて入れるだけで編集の下書きを作れます。解析はブラウザの中で行い、動画そのものはどこにも送信されません（Claude を使う場合のみ、各場面の静止画を1枚ずつ Anthropic の API に送ります）。

1. 動画ファイルをまとめてドロップし、神社の名前と仕上がりの長さ（横 1〜10分 / 縦 30〜60秒）を選びます。
2. 「おまかせ編集を開始」を押すと、次の処理を自動で行います。
   - **並べ替え**: 動画に記録された撮影日時の順（記録がない動画があるときはファイル名の順）
   - **話し声**: 撮影者が話している部分を検出し、切らずに残します。BGM を追加すると、話している間は自動で音量が下がります
   - **見どころ**: 話していない場面は、手ぶれ・ピンぼけ・暗さを判定し、安定した場面だけを切り出して指定の長さに収めます。撮り始めと撮り終わりのブレも除きます
   - **アクセス案内**: 動画に撮影場所（GPS）が記録されていれば、その座標でアクセス案内カードを作ります
3. Claude API キーを設定していれば、各場面の静止画を Claude に見せて、聖地名カード・解説テロップ・参拝作法・チャプター・動画タイトルを日本語と英語で作らせることもできます（API の利用料金がかかります）。

結果は今のタイムラインに置き換わります（Ctrl+Z で元に戻せます）。御祭神・ご利益・アクセス情報は、メモ欄に書いた情報が優先され、それ以外は Claude の知識による下書きです。公開前に必ず確認してください。
話し声の検出は音の大きさと声の高さによる簡易判定のため、風や鈴の音などを声と判定したり、小さな声を見落としたりすることがあります。

## データの保存について

- プロジェクトと素材（写真・動画・音声・録音）は、**このブラウザの中**（IndexedDB）に自動保存されます。
  同じファイルを何度追加しても（おまかせ編集のやり直しを含む）、保存されるのは1つだけです。
- **プロジェクトは複数持てます。** ヘッダーの「プロジェクト」で、新規作成・切り替え・複製・削除ができます。
  アプリを開くと、最後に開いていたプロジェクトから再開します。複製したプロジェクトは素材を共有するので、容量は増えません。
- **バックアップ**（「プロジェクト」→ 各プロジェクトの「バックアップ」）は、編集内容と素材を1つのファイル（`.sacred.zip`）にまとめて保存します。
  「バックアップから読み込む」で、別のパソコン・ブラウザでも素材ごと新しいプロジェクトとして開けます（今あるプロジェクトは置き換わりません）。
  中身は通常の ZIP ファイルで、`media` フォルダに元の写真・動画・音声がそのまま入っています。
- どのプロジェクトでも使われなくなった素材は、**使われなくなってから14日後**に、アプリを開いたときに自動で削除されます。
- ヘッダーの「保存」で書き出す JSON には、**素材ファイル自体は含まれません**（編集内容だけの軽いファイルです）。
  同じブラウザでは「読込」で素材も復元されますが、別の PC・ブラウザや、素材が削除された後（上記の14日後）は、素材を追加し直す必要があります。素材ごと残したいときはバックアップを使ってください。
- 素材を保存すると、アプリはブラウザに「保存内容を自動で消さない」よう依頼します。許可されているかは「プロジェクト」の下部で確認できます。
  許可されていない場合、パソコンの空き容量が少なくなるとブラウザが保存内容を消すことがあります。
- ブラウザの「サイトデータの削除」を行うと、プロジェクトも素材もすべて消えます。大事なプロジェクトはバックアップを取り、元の写真・動画・音声も手元に残しておいてください。
- 読み込むファイル（JSON・バックアップ）は検査され、欠けている項目は補われます。配置できない項目（長さのないクリップなど）は除いて読み込み、その件数を知らせます。

## 地図について

アクセス案内カードの地図は2種類から選べます。

- **地図画像（推奨）**: 正確な地図をアップロードして表示します。
  アプリ内の「OpenStreetMapでこの座標を開く」から地図を開き、「共有」→「画像」でダウンロードした画像を使えます。
  その場合は出典表記「© OpenStreetMap contributors」を残してください。
- **簡易地図**: 緯度・経度のピンと座標を表示する装飾的な図です（実際の道路などは表示されません）。

| キー | 操作 |
|---|---|
| Space / K | 再生 / 一時停止 |
| ← / → | 1コマ移動（Shift 併用で1秒） |
| Home / End | 先頭 / 末尾へ |
| Tab → Enter | ボタン・タブ・タイムラインのアイテムへ移動して選ぶ（Shift+Tab で戻る） |
| Alt+← / Alt+→ | 選択中のクリップ・テロップ・音声を 0.1 秒ずつ動かす |
| Alt+Shift+← / Alt+Shift+→ | 選択中のアイテムの長さを 0.1 秒ずつ変える（終わりの位置が動く） |
| S | 選択中のアイテムを再生位置で分割 |
| Delete / Backspace | 選択中のアイテムを削除（本編のクリップは後ろを詰める） |

ダイアログを開いている間は、ほかのショートカットは働きません（裏のタイムラインを誤って編集しないため）。再生中にダイアログを開くと、再生は止まります。

## キーボードだけでの操作・読み上げソフト

- Tab キーでボタン・タブ・入力欄・タイムラインのアイテムを順に移動でき、今どこにいるかが枠で示されます（マウスでクリックしたときは枠を出しません）。
- Tab キーで選んだボタンの上では、Space と Enter はそのボタンを押す操作になります。再生 / 一時停止は K がいつでも使えます。
- 左のタブ（素材・テロップなど）は、Tab キーで選んだあと ← / → で切り替えられます。
- タイムラインのアイテムは Enter で選び、Alt+矢印で動かし、Alt+Shift+矢印で長さを変えられます（動ける範囲はマウスでドラッグするときと同じです）。続けて押したキーは、まとめて1回で元に戻せます。
- ダイアログを開くとフォーカスが中に入り、Tab で外へは出ません。閉じると、開いたボタンに戻ります。
- 入力欄・ボタン・タイムラインのアイテムには名前が付いていて、読み上げソフトで内容と状態（選択中・ミュート中など）が伝わります。
- パソコンの「動きを減らす」設定がオンのときは、フェードなどのアニメーションを止めます。
- 左端をドラッグして行う開始位置のトリムは、キーボードでは「再生位置で分割（S）して前半を削除（Delete）」で行います（音声は「音声」タブの冒頭カット欄でも可）。アクセス案内カードの位置と長さは「地図」タブの開始秒・表示尺の欄で変えられます。

## 編集のしくみ

- **動画の長さ**: 最後の写真・動画の終わりにエンディングが続くよう、自動で合わせます。テロップ・案内カード・ナレーションはエンディングに重なってもよく、それより後ろにはみ出したときだけ動画が長くなります。BGM・環境音は動画の長さに合わせて切られ、最後まで流れていたものは新しい終わりまで流れます。
- **隙間**: 写真・動画のない部分は、書き出すと黒い画面になります（プレビューにはその旨を表示します）。本編のクリップを削除すると、後ろのクリップ・テロップ・音声・チャプターが詰まります。
- **つなぎ**: 「素材」タブのクリップ設定で、前のクリップからの切り替えをディゾルブ・黒フェード・白フェードにできます。切り替えの前後半分ずつにかかり、動画の元の音も一緒に切り替わります。前にクリップがないときは黒（白）からのフェードインです。
- **Bロール**: 「Bロールとして再生位置に重ねる」で追加した映像は本編の上に重なり、本編の声はそのまま聞こえます（Bロールの元音声は最初は 0%）。
- **再生速度**: 映る範囲はそのままで長さが変わり、本編では後ろのクリップも一緒にずれます。元の音は高さも変わります。

## 書き出しの設定

- **解像度 / フレームレート**: 1080p または 4K（2160p）、24 / 30 / 60fps。ビットレートは YouTube の推奨値（1080p30: 8 Mbps、1080p60: 12 Mbps、4K30: 40 Mbps、4K60: 60 Mbps）です。
- **音量の仕上げ**: 動画全体の音量を YouTube 標準（-14 LUFS）・神聖・静寂重視（-18 LUFS）・Shorts（-12 LUFS）のいずれかにそろえます（上げるのは最大 12 dB まで）。どれを選んでも、音割れを防ぐリミッター（ピーク -1.5 dBFS）がかかります。書き出し後に、仕上がりの音量とピークを表示します。
- **音声の作り方**: 書き出す音声は10秒ずつミックスし、映像と並行してエンコードします。音量をそろえるときは、先に全体を1〜2回通して測ってから仕上げます。使う素材も、鳴っている間だけ読み込みます（5分以内の音源はファイル全体、それより長い音源と動画の音は必要な部分だけ）。そのため、動画が長くなっても音声のためのメモリは増えません。
- **保存方法**（Chrome / Edge）: 「保存先を選んで直接書き込む」にすると、書き出しながらファイルへ書き込むため、長い動画や 4K でもメモリを使いません（3分以上の動画では最初からこちらが選ばれます）。中止したときは書きかけの内容を残しません（保存先に選んだファイルは、空のまま残ることがあります）。

## 既知の制限

- 「ダウンロード」で書き出すときは、完成した動画をいったんブラウザのメモリに置きます。長尺（数十分以上）や 4K の動画は「保存先を選んで直接書き込む」を使ってください（Chrome / Edge のみ）。
- 5分を超える音源ファイルや動画の音で、サンプリング周波数が 48 kHz でないもの（44.1 kHz など）は、簡易な方法（前後4点からの補間）で 48 kHz に変換します。通常の BGM（5分以内）はブラウザの高品質な変換を使います。
- 色補正は Canvas のフィルター機能を使います。対応していないブラウザでは、明るさ・コントラスト・彩度が反映されない場合があります。
- 動画素材の形式（コーデック）によっては、ブラウザが読み込めず書き出しに反映されない場合があります（書き出し完了時に警告を表示します）。
- バックアップの作成中は、素材を一度すべて読み取ります（数GBの動画では数十秒〜数分かかります）。保存先はブラウザのダウンロードフォルダです。
- PC での利用を想定しています（スマートフォンの画面には対応していません）。

## 開発の進め方

- **確認**: 変更したら `npm run lint`（型チェックとリント）と `npm test`、画面や書き出しに関わる変更は `npm run test:e2e` を実行します。
- **CI**: GitHub に push したとき・プルリクエストを作ったときに、同じ確認（型チェック・リント・自動テスト・ビルド・ブラウザテスト）が GitHub Actions で自動的に走ります（`.github/workflows/ci.yml`）。
- **リント**: [oxlint](https://oxc.rs/docs/guide/usage/linter.html) を使います（typescript-eslint が TypeScript 7 に未対応のため）。無効にしている規則とその理由は `.oxlintrc.json` に書いてあります。
- **整形**: Prettier の設定（`.prettierrc.json`）を用意しています。既存のコード全体への適用はまだ行っていません（差分が大きくなるため）。`npm run format` で一括整形できます。
